# Machine Learning

Bahan presentasi tentang model klasifikasi 3 kelas (Lulus, Dipertimbangkan, Tidak Lulus) yang membandingkan Random Forest dan XGBoost.

Model dan API-nya adalah bagian ASAH milik tim. Folder ini berisi analisis tambahan untuk matkul, misalnya perbandingan metrik, tuning, dan interpretasi fitur, dengan rujukan ke kode model tim.
