# Pemrograman Lanjut

Bahan presentasi yang membahas cara aplikasi LMS dibangun: arsitektur Next.js dan Server Actions, akses data dengan Prisma, autentikasi, kontrol akses per kelas, dan pengujian.

Kodenya sendiri tetap berada di folder aplikasi (`app/`, `lib/`, `prisma/`). Folder ini hanya berisi penjelasan, diagram, dan catatan presentasi yang merujuk ke kode tersebut.
